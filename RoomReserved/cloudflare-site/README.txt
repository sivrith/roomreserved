ROOMRESERVED LUXURY FRONTEND — INTERACTIVE DEMO

WHAT THIS PACKAGE IS
A responsive static frontend for Cloudflare Pages. It is designed to display as a website without running Java/Spring on a Workers runtime. The pages include a luxury stay collection, room details, sample availability states, multi-step booking UI, price breakdown, demo promo codes, guest details, payment preference selection, browser-local demo booking references, notifications, reviews preview, saved stays, map-search links, and an operations preview.

DEPLOY THE STATIC FRONTEND
1. Open Cloudflare Dashboard → Workers & Pages → Create application / Pages project. Exact UI labels may vary.
2. Choose direct upload if available and upload the CONTENTS of this folder (index.html must be at the root), or create a Git repository and connect the folder.
3. Deploy and open the exact URL Cloudflare provides.
4. Check desktop and mobile widths. The images use remote Unsplash URLs and Google Fonts, so those third-party services must be reachable for those assets to load.

DEMO-ONLY LIMITATIONS — READ BEFORE LAUNCH
- Listings, rates, reviews, room counts, availability states, fees, tax rate, policies, and property location are sample content. They are not live or verified.
- Booking references and notification history are stored in the visitor's browser localStorage only. They are NOT reservations and do not reach a property, database, or admin.
- Availability and room counts are mock inventory. There is no real-time WebSocket/SSE feed, reservation hold, expiry service, or concurrency lock.
- Sign-in, registration, payment choice, newsletter, reviews, and admin screen are UI previews only.
- WELCOME10 and eligible Friday-arrival WEEKEND15 are demo discount calculations only. The backend must validate any real offer.
- Price breakdown uses illustrative 12% tax and 5% service fee. Replace these with approved property and jurisdiction rules.
- Google Maps links search for Cebu City only. No property address or coordinates were supplied; no exact location is asserted.
- Do not use this static package to accept real payments, reservations, or personal guest information.

PRODUCTION CONNECTION REQUIRED
Deploy the Spring Boot backend and PostgreSQL database on a Java-capable host, then connect the frontend to authenticated HTTPS API endpoints. Before accepting customers, implement and test transactional inventory locking, expiring holds, server-side pricing and promotion validation, payment webhook verification and idempotency, role-protected admin endpoints, verified-stay reviews, notification persistence/deduplication, email/push delivery, backups, monitoring, privacy notices, and restore drills. The current backend has not been certified to meet these requirements.
